Project status

Use case

This web-node plugin runs pre-render scripts of your application, e.g. to generate static HTML snapshots of a single page application for search engines or faster first page loads. You provide the scripts, the plugin finds, runs and cleans up after them.

Features included:

  • Finds pre-render scripts by file name anywhere in your application.
  • Runs them in parallel, each in its own directory.
  • Removes generated output directories on shutdown.
  • Hooks to change the list of scripts and their command line arguments.

Content

Installation

Install the plugin next to web-node. web-node discovers every installed package whose name ends with "-web-node-plugin" automatically:

yarn add web-node pre-render-web-node-plugin

Example

Add an executable script named "preRender.js" (or "pre-render.js", "preRenderer.js", "pre-renderer.js") to your application. The plugin runs it via the shell from its own directory. The last argument tells whether a cache may be used ("true" or "false"). Write the results to a directory named "preRendered":

#!/usr/bin/env node
import('fs/promises').then(async ({mkdir, writeFile}) => {
    await mkdir('preRendered', {recursive: true})
    await writeFile('preRendered/index.html', '<h1>Pre-rendered</h1>')
})

chmod +x preRender.js

Enable rendering on startup and after configuration updates in your application's "package.json":

{
    "webNode": {
        "preRender": {
            "renderAfterConfigurationUpdates": true
        }
    }
}

Without this option nothing runs automatically. Other plugins can then trigger it via "services.preRender.render(state)".

Configuration

All options live below "webNode.preRender":

  • "locations.executer.fileNames": File names of pre-render scripts.
  • "locations.executer.include" and "locations.executer.exclude": Directories to search and to skip. "node_modules", "src", "log", "database" and similar folders are excluded by default.
  • "locations.output.directoryNames": Names of output directories below each script which are removed on shutdown. Defaults to "preRendered".
  • "locations.output.exclude": Paths below a script to keep on shutdown.
  • "cache": Value passed as last argument to each script. Defaults to "false".
  • "renderAfterConfigurationUpdates": Run on startup and after each configuration change. Defaults to "false".

Hooks and services

  • "prePreRendererRender": Receives and returns the list of found scripts.
  • "prePreRendererCLIParameter": Receives and returns the arguments for each script.
  • "postPreRendererRender": Runs after all scripts finished.
  • "services.preRender.render(state)": Runs all scripts. Additional arguments can be given as "state.data".
  • "services.preRender.renderFile(path, arguments)": Runs a single script.
